
# Tsumaranai Forum

An open-source retro internet forum inspired by the web of the 2000s.

## About

Tsumaranai (つまらない) is a personal web project combining a traditional discussion forum, a blog, and a space for creative work.

The project aims to preserve the atmosphere of the early internet while using modern technologies and security practices.

## Goals

- Build a fully functional discussion forum.
- Support multiple visual themes.
- Provide space for blogging and creative content.
- Support international users and future localization.
- Preserve the project's development history.
- Keep the software simple, maintainable, and reusable.

## Technology

- Python / Flask
- PostgreSQL
- Jinja2
- Apache / Gunicorn
- Debian Linux

## Status

Early development. The first milestone is a minimal working Flask application.
